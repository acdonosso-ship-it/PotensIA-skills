# Potensia Skills para Claude

Skills diseñados por [Potensia](https://potensia.ai/) para directivos y equipos que quieren usar la inteligencia artificial como copiloto de pensamiento, no como herramienta de ejecución.

Estos skills funcionan en [Claude.ai](https://claude.ai) y están construidos bajo el modelo de las **3 A de adopción de IA**: Automatizar, Aumentar y Agenciar. Los skills de este repositorio viven en la segunda A — **Aumentar** — porque están diseñados para elevar la calidad del pensamiento humano, no para reemplazarlo.

---

## ¿Qué es un skill de Claude?

Un skill es un marco de trabajo instalado en tu entorno de Claude.ai que se activa automáticamente cuando el contexto lo amerita. A diferencia de un prompt, que es una instrucción puntual que tienes que recordar y copiar cada vez, un skill vive en tu configuración y opera como un colega especializado que entra cuando lo necesitas.

## Skills disponibles

### 1. Matriz de decisión ponderada

**Carpeta:** `decision-matrix-skill/`

Un framework estructurado de 7 fases para tomar decisiones complejas con rigor analítico. El skill actúa como copiloto de pensamiento: hace las preguntas que el usuario está evitando, detecta contradicciones entre lo que dice que importa y cómo lo está ponderando, propone calificaciones basadas en la casuística del usuario y aplica un análisis de Red Team a la opción ganadora antes de declarar un resultado.

**Cuándo se activa:** cuando describes una decisión difícil, cuando tienes varias opciones y no sabes cuál elegir, cuando usas frases como "no sé qué hacer", "estoy entre dos opciones" o "ayúdame a decidir".

**Lo que hace en cada fase:**

| Fase | Qué hace |
|---|---|
| 1. Contexto | Entiende la decisión real detrás de la decisión aparente |
| 2. Criterios | Define los criterios que emergen de tu situación específica |
| 3. Pesos | Te desafía a jerarquizar honestamente, no decorativamente |
| 4. Calificaciones | Propone y justifica, no solo pregunta |
| 5. Matriz | Construye la tabla ponderada desde tu casuística |
| 6. Red Team | Ataca la opción ganadora antes de que la ejecutes |
| 7. Reflexión | Resume prioridades reales, trade-offs y robustez de la decisión |

**Complemento:** este skill se puede usar junto con el [instrumento interactivo de Potensia](https://claude.ai) — una herramienta visual con análisis de sensibilidad en tiempo real disponible directamente en Claude.ai.

## Cómo instalar un skill en Claude.ai

1. Descarga la carpeta del skill que quieras usar
2. Entra a [claude.ai](https://claude.ai) y abre la configuración de tu cuenta
3. Ve a la sección **Skills**
4. Arrastra el archivo `.skill` o sube la carpeta con el `SKILL.md`
5. El skill queda activo y se activará automáticamente cuando el contexto lo requiera
